
# Spek - A Picture of a Recording You Own

[![Open Spek](https://img.shields.io/badge/Open-Spek-44403c?style=for-the-badge&logoColor=white)](https://f6492950.github.io/.github/Spek)

## About Spek

Spek draws a spectrum of an audio file you already have, so you can see whether a recording uses the high frequencies you expect or looks cut off. It is a viewer for your own exports, rips you are allowed to inspect, or takes you recorded. It does not play a store, and it does not repair a file. A pretty graph is not a license.

You use it to compare two exports of the same material you made, or to see if a file you encoded is obviously dull. You do not use it as a reason to replace a commercial track with a different download.

Open the file, look once, and close it. Spek does not edit the audio.

![Spek spectrum of one audio file the user owns](https://spekoptics.ca/cdn/shop/files/SPEK_Social.jpg?v=1787594270)

## How to Use Spek

1. Export or locate one audio file you may inspect.  
2. Open it in Spek and wait for the graph.  
3. Look at whether the top of the spectrum is present or hard-cut.  
4. If you are comparing, open the other export of the same recording you made.  
5. Close Spek. Decide in the editor or the player, not by staring at a single screenshot.

---

## Features Included in Spek

- A spectrum view of a local audio file  
- A quick look at bandwidth and an obvious cutoff  
- Comparison by opening another file you encoded  
- No editing of the audio  
- A small window that does not replace a player  
- Support for common audio files you can already store  
- A graph that updates when the file finishes loading  
- Nothing uploaded

---

## Troubleshooting

- The graph is empty? The file may not be audio, or it did not finish loading. Try a file you know plays.  
- Two files look different and you did not encode both? Do not "fix" that by downloading another copy.  
- You wanted to change the sound? Spek will not. Use an editor on a copy of a recording you may edit.
